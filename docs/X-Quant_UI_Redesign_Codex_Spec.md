# X-Quant 策略驾驶台 UI 重构实施规范

> 文档用途：直接交给 Codex，在现有 X-Quant 项目中完成前端 UI 重构。  
> 文档版本：v1.0  
> 日期：2026-09-09  
> 适用范围：策略驾驶台首页、全局导航、主题与基础视觉规范。  

---

## 1. Codex 执行指令

请先阅读本仓库的目录结构、`package.json`、现有路由、状态管理、组件库、图表库、样式方案和 API 调用方式，再开始修改。

必须遵循以下原则：

1. **沿用现有技术栈**，不得为了页面美化擅自替换前端框架、路由、状态管理或请求库。
2. **不修改现有后端接口与核心业务逻辑**。如字段不适合直接展示，应在前端增加 ViewModel 或 Adapter 层完成映射。
3. 优先复用现有组件、图标库、图表库和设计变量；不存在时再新增轻量实现。
4. 保证现有页面路由、权限控制、任务操作和数据查询能力继续可用。
5. 所有用户可见文案必须中文化，技术标识仅作为次级信息展示。
6. 页面必须支持浅色和深色主题；**浅色主题为默认主题**。
7. 先完成桌面端体验，同时保证 1280px 宽度下可正常使用，不出现横向页面滚动。
8. 不得使用大面积渐变、玻璃拟态、霓虹光效、重阴影或无业务价值的动画。
9. 股票涨跌色与系统状态色必须分开定义，禁止混用。
10. 完成代码后运行项目现有的 lint、typecheck、test 和 build；修复由本次改造引入的问题。

## 2. 改造目标

将当前偏“服务器监控后台”的首页，重构为面向中国量化投资者的“量化决策与策略运行驾驶台”。

用户进入首页后，应在第一屏快速回答以下问题：

1. 今日组合盈亏如何？
2. 当前有多少策略正在运行？
3. 是否存在需要立即处理的风险或异常？
4. 今天产生了多少买卖信号？
5. 组合净值、回撤和基准表现如何？
6. 最近的实验、回测和任务运行到什么状态？

设计关键词：

- 专业
- 克制
- 清晰
- 中文任务导向
- 数据优先
- 风险优先
- 适合长时间查看

## 4. 当前页面主要问题

1. 首页核心指标是“运行实例、待处理计划、待审批、近期实验”，与投资决策优先级不一致。
2. 顶部同时出现“驾驶台”和“策略驾驶台”，标题重复。
3. 页面右侧和下方存在大面积无意义留白。
4. 顶部紫色横线、绿色导航选中态、红绿状态色同时出现，品牌色不统一。
5. 背景、卡片、表格之间明度过于接近，页面层级不清晰。
6. `SUCCEEDED`、`RUNNING`、`FAILED`、`DEMO_SNAPSHOT` 等文案未中文化。
7. ISO 8601 时间直接展示，不符合中文用户阅读习惯。
8. 正常状态占据过多页面空间，异常信息反而不够突出。
9. 实验表格缺少耗时、失败原因和明确的行级操作。
10. 页面更像技术运维面板，未突出收益、信号、回撤、持仓和风险。

### 5.2 导航规则

- 展开宽度：`208px`。
- 收起宽度：`64px`。
- 菜单项高度：`40px`。
- 一级分组标题使用 11–12px 弱化文本。
- 当前项使用浅蓝背景、蓝色图标和蓝色文字，或使用 3px 蓝色左侧指示条。

- 菜单异常数量使用小型数字徽标，例如“持仓与风险 2”。
- 团队审批功能仅在相关功能启用时显示；个人本地模式不在首页突出“待审批”。
- Logo 区域与顶部栏同高，避免视觉错位。
- 侧栏底部可放置主题切换、系统设置和当前用户入口。

## 7. 策略驾驶台首页详细设计

## 7.1 页面头部

页面顶部只保留一个主标题：

```text
策略驾驶台
管理策略运行、组合风险与交易信号
```

标题下方展示简洁状态行：

```text
A股交易中 · 数据更新于 09:30:12 · 30 秒后自动刷新
```

右侧操作区：

```text
[演示环境] [市场：全部] [刷新数据] [新建回测]
```

规则：

- “新建回测”为唯一主按钮。
- “刷新数据”为次级按钮，刷新中显示旋转图标和“刷新中”。
- “演示环境”是状态标签，不使用紫色主按钮样式。
- 环境标签建议使用浅橙背景，文字为深橙色。
- 市场选择器支持未来扩展：全部、A股、港股、美股、数字货币。
- 数据更新时间只展示一次。
- 正常时不展示冗长的技术提示。
- 只有出现异常时，在页面头部下方插入警告条。

异常条示例：

```text
组合最大回撤达到 8.2%，已超过 8.0% 预警线。    [查看风险] [暂时忽略]
```

## 7.2 第一排：核心指标卡

第一排固定四张卡片：

| 指标 | 主值示例 | 辅助信息示例 | 点击行为 |
|---|---:|---|---|
| 今日盈亏 | `+¥ 1,258.20` | `+0.82% · 较昨日 +0.31%` | 打开组合分析，筛选今日 |
| 运行策略 | `3 个` | `已部署 8 个` | 打开部署中心，筛选运行中 |
| 待处理风险 | `2 项` | `高风险 1 · 提醒 1` | 打开持仓与风险，筛选未处理 |
| 今日信号 | `12 条` | `买入 7 · 卖出 5` | 打开信号中心，筛选今日 |

无实盘数据时允许降级为：

- 运行中策略
- 今日生成信号
- 待处理风险
- 进行中实验

但组件名称和接口映射应便于后续无缝切换到组合盈亏版本。

### 指标卡视觉规范

- 高度：`104px`，最小高度不低于 `96px`。
- 圆角：`10px`。
- 内边距：`18px`。
- 标题字号：`13–14px`。
- 主数字号：`28px`，字重 600。
- 辅助信息字号：`12px`。
- 图标：18px，放置在右上角或标题左侧。
- 默认不使用明显阴影，仅使用 1px 边框。
- Hover 时边框切换为主色浅色，允许 `translateY(-1px)`，动画不超过 150ms。
- 卡片可点击时必须有鼠标指针、键盘焦点和可访问标签。
- 主值为零时仍需有说明，避免单独显示空洞的大号 `0`。

零值示例：

```text
运行策略
0 个
暂无运行中的实盘策略
```

### 涨跌色规则

- 市场上涨：红色。
- 市场下跌：绿色。
- 市场持平：灰色。
- 系统成功：绿色。
- 系统失败：红色。

这两套语义必须使用不同变量名称，禁止复用同一个 `success` 或 `danger` 变量表示市场涨跌。

## 7.3 第二排左侧：组合表现

占据 8/12 栅格。

标题区：

```text
组合表现                                  [今日] [近7日] [近30日] [今年]
总收益 +12.36%   今日 +0.82%   最大回撤 -4.21%   基准 +8.09%
```

图表能力：

- 组合净值曲线。
- 基准指数曲线。
- 回撤区域或独立回撤指标。
- 买入、卖出信号标记。
- 时间范围切换。
- 实盘、模拟和演示数据切换。
- Tooltip 展示日期、组合净值、基准值、当日收益和回撤。
- 图例支持开关。
- 图表随容器宽度响应式变化。

图表实现要求：

1. 优先复用现有图表库。
2. 图表高度建议 300–340px。
3. 不使用 3D 图表。
4. 网格线必须弱化。
5. 数据点较多时不得逐点绘制大图标。
6. 加载时显示骨架屏，不显示空白卡片。
7. 数据量为零时显示完整空状态。

空状态文案：

```text
暂无组合表现数据
部署策略或导入交易记录后，这里将展示收益、基准与回撤曲线。

[部署策略] [导入交易记录]
```

## 7.4 第二排右侧：风险与待办

占据 4/12 栅格，与组合表现卡片等高或视觉等高。

内容按紧急程度排序：

```text
风险与待办                                      查看全部

● 高风险   组合回撤超过预警线                         1
● 待处理   行情数据源同步失败                         1
● 提醒     EMA-20 策略将于 14:55 执行                2
● 正常     当前无持仓集中度风险
```

风险级别：

- `critical`：高风险，红色。
- `warning`：待处理，橙色。
- `info`：提醒，蓝色。
- `normal`：正常，绿色。

显示规则：

- 每项显示图标或圆点、级别、标题、数量或时间。
- 标题最多两行，超出省略。
- 点击行进入对应详情页并带筛选参数。
- 高风险事件必须固定在顶部。
- 正常项不得盖过异常项。
- 无风险时展示积极但简短的空状态。

无风险示例：

```text
暂无风险事件
组合级风控规则运行正常

查看风控规则 →
```

## 7.5 第三排：最近实验

使用整行 12 栅格卡片。

标题区：

```text
最近实验                                            [查看全部] [新建实验]
```

推荐列：

| 列 | 展示要求 |
|---|---|
| 实验名称 | 中文名称为主，技术 ID 作为次级信息 |
| 策略 | 中文策略名，必要时显示版本 |
| 数据范围 | 日期范围或“近 3 年”等描述 |
| 状态 | 中文状态，使用图标/圆点 + 文本 |
| 进度 | 进度条 + 百分比 |
| 已用时间 | 如 `2分18秒` |
| 操作 | 查看、停止、重试、查看原因等 |

示例：

| 实验名称 | 策略 | 数据范围 | 状态 | 进度 | 已用时间 | 操作 |
|---|---|---|---|---:|---:|---|
| S-BR 合成夹具四组回放 | 突破回踩 | 2024-01 至 2026-08 | 已完成 | 100% | 2分18秒 | 查看报告 |
| EMA 基线回测比较 | EMA 20/60 | 近3年 | 运行中 | 65% | 1分06秒 | 查看 / 停止 |
| 参数网格 24 组预注册 | 突破回踩 | 24组参数 | 失败 | 12% | 18秒 | 查看原因 / 重试 |

### 状态映射

```text
SUCCEEDED  -> 已完成
RUNNING    -> 运行中
FAILED     -> 失败
PENDING    -> 等待中
CANCELLED  -> 已取消
PAUSED     -> 已暂停
```

### 表格规则

- 表头高度：40px。
- 行高：48–56px。
- 实验名称第一行中文名称，第二行显示技术 ID。
- 技术 ID 使用 12px 等宽字体、弱化颜色。
- 状态不只依赖颜色，必须同时显示中文文字。
- 进度条右侧显示百分比。
- 失败行允许使用极浅红背景，但不可使用高饱和整行红色。
- 运行中任务提供“查看”和“停止”。
- 失败任务提供“查看原因”和“重试”。
- 已完成任务提供“查看报告”和可选“复制实验”。
- 表格支持按状态、策略和时间筛选。
- 支持分页或“查看更多”，不能无限延长首页。
- 小屏下优先隐藏“数据范围”和“已用时间”，操作列保持可见。

## 7.6 底部：系统健康状态栏

将当前大块“数据状态、风控状态、运行健康”卡片压缩为一行紧凑状态栏：

```text
行情数据正常 · 风控服务正常 · 调度服务正常 · 通知渠道 2/2 正常
```

每项显示：

- 状态图标。
- 服务名称。
- 简短结果。
- Hover 或点击后再展示最后更新时间、数据源名称、延迟和详细错误。

正常状态只显示简短结果；异常时升级为顶部警告条或风险待办项。

异常示例：

```text
行情数据延迟 8 分钟                           [查看数据源]
```

## 8. 中文化与格式规范

### 8.1 文案映射

| 当前文案 | 新文案 |
|---|---|
| 数据截止 2026-09-08T09:30:00+08:00 | 数据更新于 2026-09-08 09:30 |
| 模式 demo | 演示环境 |
| DEMO 合成数据 | 使用演示数据 |
| DEMO_SNAPSHOT | 演示快照 |
| 风控状态 OK | 风控正常 |
| 运行健康 | 系统运行状态 |
| 心跳 2026-09-08T09:30:00+08:00 | 服务正常 · 最后心跳 09:30 |
| SUCCEEDED | 已完成 |
| RUNNING | 运行中 |
| FAILED | 失败 |
| PENDING | 等待中 |
| 组合硬风险优先于新策略信号 | 新信号将先通过组合级风险校验 |
| 本地进程休眠或退出后不会自动发送过期提醒 | 后台服务未常驻，部分提醒可能延迟 |

### 8.2 时间格式

- 完整时间：`YYYY-MM-DD HH:mm:ss`。
- 当日时间：`HH:mm:ss`。
- 日期范围：`YYYY-MM-DD 至 YYYY-MM-DD`。
- 相对时间可用于辅助信息：`刚刚`、`3 分钟前`、`昨天 14:20`。
- 默认不展示 `T`、毫秒和 `+08:00`。
- 时区可在 Tooltip 中展示为“北京时间 UTC+8”。

### 8.3 数字格式

- 金额：`¥ 12,580.00`。
- 收益率：`+3.26%`、`-1.08%`。
- 大数允许使用“万”“亿”，Hover 展示完整数值。
- 金额、收益率和数量使用等宽数字。
- 表格中的数字默认右对齐。
- 正数收益必须带 `+`，零值显示 `0.00%`。
- 避免前后端重复乘以 100；在 Adapter 层明确收益率字段是小数还是百分数。

## 10. 组件规范

## 10.1 按钮

按钮层级：

1. 主按钮：蓝色实心，仅用于当前区域最重要操作。
2. 次级按钮：白底或透明底 + 边框。
3. 文本按钮：用于表格行操作和低优先级入口。
4. 危险按钮：仅用于停止任务、删除和撤销部署等高风险动作。

规则：

- 同一区域最多一个主按钮。
- 按钮高度建议 32px 或 36px。
- 图标按钮必须有 Tooltip 和 `aria-label`。
- 危险操作需要二次确认；“停止运行中实验”可使用轻量确认弹窗。

## 10.2 标签与状态

状态标签不使用全大写英文。

建议形式：

```text
● 已完成
● 运行中
● 失败
● 等待中
```

- 图标/圆点 + 中文文本。
- 使用浅色背景和语义色文字。
- 不得只依赖颜色区分。
- 标签高度建议 24px。

## 10.3 表单控件

- 标签位于控件上方或左侧，整个系统保持一致。
- 筛选器优先使用清晰中文选项。
- placeholder 说明输入目的，不重复字段名。
- 数字输入必须明确单位。
- 日期范围选择器默认使用北京时间。

## 10.4 提示反馈

- 成功操作使用简短 Toast。
- 普通错误使用错误 Toast，并保留原页面数据。
- 阻断性错误使用 Alert 或结果页。
- 数据刷新失败时不得清空上一版有效数据。
- 错误提示需要包含用户可执行的下一步，例如“重试”“检查数据源”。

## 11. 页面状态设计

所有核心区块必须实现以下状态：

### 11.1 Loading

- 卡片使用骨架屏。
- 表格使用 5 行骨架。
- 图表使用矩形骨架和标题占位。
- 不使用全页无限旋转图标阻塞用户。

### 11.2 Empty

空状态必须包含：

- 简短标题。
- 一句原因或用途说明。
- 0–2 个明确操作。

示例：

```text
暂无运行中的策略
部署策略后，可在此查看实时状态和风险。

[部署策略]
```

### 11.3 Error

示例：

```text
组合表现加载失败
上次有效数据更新于 09:28:30。

[重新加载] [查看数据源]
```

- 保留上次有效数据时，需要明确标注数据时间。
- 不得只显示技术堆栈或后端英文错误。
- 详细错误可收纳在“查看详情”中。

### 11.4 Permission Denied

```text
暂无查看组合资产的权限
请联系管理员开通“组合只读”权限。
```

### 11.5 Demo Mode

- 演示数据必须有持续但不干扰的标识。
- 禁止让用户误认为是实盘数据。
- 涉及交易、部署或通知时再次提示“当前为演示环境”。

## 12. 交互规范

### 12.1 指标卡跳转

- 今日盈亏 → 组合分析页，自动筛选“今日”。
- 运行策略 → 部署中心，自动筛选 `RUNNING`。
- 待处理风险 → 风险列表，自动筛选“未处理”。
- 今日信号 → 信号中心，自动筛选“今日”。

应通过路由查询参数保留筛选条件，例如：

```text
/portfolio?range=today
/deployments?status=running
/risks?status=open
/signals?date=today
```

实际路由以现有项目为准，不得强制改成以上路径。

### 12.2 局部刷新

- 点击刷新只更新首页数据，不整页 reload。
- 刷新中按钮进入 loading 状态。
- 数据更新后数值可短暂出现浅色高亮，持续 300–500ms。
- 刷新失败保留旧数据并提示失败。
- 自动刷新倒计时不能造成布局跳动。

### 12.3 表格操作

- 行点击可打开详情，但操作列必须提供显式入口。
- 点击行内按钮时不得触发行跳转。
- 停止任务需要确认。
- 重试失败任务后立即更新该行状态。
- 长技术 ID 提供复制按钮或 Tooltip。

### 12.4 风险事件

- 高风险事件需明显但克制地突出。
- 风险处理动作需记录处理结果。
- “暂时忽略”必须明确忽略时长或条件，不能永久隐藏无记录。
- 已处理风险可从首页移除，但在风险列表中保留审计记录。

### 16.3 数据防御

- 所有数字字段处理 `null`、`undefined`、`NaN` 和无限值。
- 进度限制在 0–100。
- 后端返回未知状态时显示“未知状态”，并记录前端告警，不让页面崩溃。
- 时间解析失败时显示 `--`，不要展示 `Invalid Date`。
- 收益率字段需要通过单元测试确认单位。
- API 失败时允许各区块独立降级，不应因一个请求失败导致整页不可用。

## 17. 数据请求与性能

- 优先复用现有数据请求机制。
- 首页多个接口允许并行请求。
