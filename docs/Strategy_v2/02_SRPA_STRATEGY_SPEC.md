# XQ-SRPA v0.1：可编码、可回测的量化策略规则书

> SRPA = Support/Resistance + Price Action。  
> 策略族：市场状态路由、支撑阻力定位、价格行为确认、相对强弱排序、独立组合风控。  
> 首个完整实现：`xq.srpa.breakout_retest.long@0.1.0`。  
> 当前状态：**已形成规则规格，未完成本项目收益验证，不得标注“实盘验证通过”**。  
> 本文的参数是待测试起点，不是最优参数或获利保证。所有“买入/卖出”描述均为策略规则；实际模式先采用仿真与人工操作提醒，不自动连接券商。

本文与 `01_SOURCE_AUDIT.md` 配套。`[Rxx]` 是来源审查文档中的编号。来自上游的思想与本项目新增的工程化规则分别标注，避免把新规则说成上游已经证明有效。

## 1. 策略究竟交易什么

策略假设：在可交易、流动性足够且市场没有进入禁入状态时，**具有明确上行结构的股票，突破既有阻力后回测该区域，并再次出现收盘确认**，可能比任意追涨有更清晰的失效位置。相对强弱只决定候选优先级，不替代入场。该假设借鉴 PA 的突破测试与顺势思想、SR 的区域识别，再用独立退出和账户规则补全。[R06][R08][R12]

必须同时回答六个问题：交易谁、什么时候产生信号、什么条件下允许成交、错在哪里、怎样退出、这次风险占账户多少。任何一项缺失时，该对象只属于研究候选，不属于可操作方案。

### 1.1 范围与模式

| 维度 | v0.1 默认值 |
|---|---|
| 市场 | A 股普通股票作为第一实现假设；市场/板块规则必须配置并按生效日期读取 |
| 方向 | 只做多、无杠杆、无摊平、无金字塔加仓 |
| 决策频率 | 每个交易会话结束后，使用完整且已校验的日线 |
| 执行 | 下一交易会话；先仿真与人工提醒，不承诺以开盘价真实成交 |
| 策略组装 | 先只启用突破回测；H2 和偏多区间反弹通过各自验收后再启用 |
| 预测 | 默认 `rule_only`；统计模型是独立可审批版本，LLM 不在交易必经链路 |
| 数据/权益 | 本地授权快照、点时股票池、公司行为、市场日历、真实成交与现金账本 |

### 1.2 两种执行口径不能混用

**EOD_ASSIST，默认。** 收盘判断入场、止损、止盈、趋势失效，下一交易会话尝试执行。止损价是决策阈值，不是保证成交价。回测用 `next_open_reference` 作为参考成交模型并计费/滑点；真实运行必须以用户导入的成交为准。只有日线数据时，无法精确验证用户开盘后数分钟才处理通知的成本，应标记延迟风险，并用实际仿真/人工成交差异评估。

**MONITORED_INTRADAY，后续。** 必须具备授权盘中行情、可用的执行/人工监控条件、独立触发器与更细粒度回放。不能用每日最低价假装日内止损总能成交，也不能把 EOD 回测成绩贴到盘中版本。没有券商条件单能力时，本地“虚拟止损”只是提醒。

## 2. 策略资产与组合方式

| ID | 角色 | 默认状态 |
|---|---|---|
| `F-PA` | EMA、ATR、K 线收盘位置、重叠、确认枢轴、突破/回收事件 | 必须实现与测试 |
| `D-SR` | 因果关键位区域检测，参考 V3 的定位/排序分离 | 必须实现与测试 |
| `G-REGIME` | 个股状态及大盘新开仓闸门 | 必须实现与测试 |
| `S-BR` | 突破→保持→回测→收盘确认 | 首个交易策略 |
| `S-H2` | 上行背景中，两次不同回撤腿后的二次确认 | 第二阶段，默认关闭 |
| `S-RG` | 偏多区间的下边缘收盘反弹 | 第三阶段，默认关闭 |
| `F-RS` | 中期相对强弱横截面排序 | 默认作为排序，不作为额外胜率 |
| `P-TOUCH` | 区域未来接触事件预测 | 雷达/研究用途，不是交易获利概率 |
| `P-REACT` | 接触后守住/突破/超时的条件分布 | 研究用途，必须注明条件 |
| `P-TRADE` | 匹配实际执行规则的成本后收益与盈利概率 | 通过时间外验证后才可过滤交易 |
| `R-PORT` | 持仓、现金、风险预算、敞口、交易约束 | 全局优先；不可被策略或 LLM 覆盖 |

同一账户同一股票同一决策时点只允许一个新增净多头计划。多个策略命中时，按固定顺序 `S-BR > S-H2 > S-RG` 选主计划，其他命中保存为解释；不是叠加三份仓位。更换优先级生成新版本。已有仓位的退出由入场绑定的版本负责。

## 3. 时点、数据与计算契约

### 3.1 统一时间语义

` t ` 表示交易会话索引，不是简单自然日。主序列从旧到新，所有时间戳带时区，存储统一 UTC。策略只看到 `available_at <= decision_at` 且 `is_final=true` 的记录。

每根 K 线至少包含 `instrument_id, session_id, open, high, low, close, volume_shares, turnover_currency, source, received_at, available_at, revision_id`。历史回放与在线恢复回放应区分：前者依据供应商可核实的历史发布时间/版本，后者依据本系统实际收到记录的时间。`received_at` 是本次接收时间，不能伪造为多年前。若只有当前下载的历史数据、无法核实当时版本，可做标为 `VINTAGE_UNVERIFIED` 的探索回测，不能宣称已排除数据修订泄漏。

必须验证 `low <= min(open,close) <= max(open,close) <= high`、价格有限且为正、数量非负、序列有序、不重号。停牌、未上市、未知缺失和供应商漏数是不同状态，不能统一前向填充成可交易价格。

**禁止使用完整数据帧中当前时点之后的行。** 高周期指标只能使用已结束周/月的 K 线；周三不能用周五收盘。跨股票横截面必须采用同一个数据截止时点和缺数政策。

### 3.2 价格与公司行为

成交、现金、持仓数量、涨跌幅检查使用真实原始价格与当时适用规则。技术计算使用 `decision_at` 当时已知公司行为构成的统一调整口径，保存因子快照，输出区域再映射到该时点可交易价格。

不可把今天下载的整条前复权曲线无条件当作多年前可见数据；也不可声称“后复权”三个字就保证所有供应商修订都是点时安全。拆并股、分红等发生时，冻结结构位按照当时已知映射转换，生成 `level_rebase_event`；不能凭更新后的历史曲线偷偷改变过去信号。无法正确处理的公司行为应阻止新增计划并提示人工核查。

成交量只有与股数单位变化一致时才调整，现金分红不凭空改变股数。技术收益序列与含分红总回报序列分开保存，动量/基准绩效使用明确的总回报口径。

### 3.3 指标精确定义

| 指标 | v0.1 定义 |
|---|---|
| EMA(n) | 首 n 个有效收盘的均值为种子，之后 `EMA_t = 2/(n+1)*C_t + (1-2/(n+1))*EMA_(t-1)` |
| TR | `max(H-L, abs(H-C_prev), abs(L-C_prev))`；序列首项取 `H-L` |
| ATR(14) | 前 14 个 TR 均值为种子，此后 Wilder 递推 `(13*ATR_prev+TR)/14` |
| CLV | `(C-L)/(H-L)`；零幅 K 线设为 0.5，不能作为强信号棒 |
| body_ratio | `abs(C-O)/(H-L)`；零幅设 0 |
| overlap | 相邻两棒高低区间交集长度/并集长度；零并集视为 1 |
| overlap10 | 最近 10 对已完成相邻 K 线 overlap 均值 |
| ER20 | `abs(C_t-C_(t-20))/sum(abs(diff(C)), 最近20期)`；分母为零设 0 |
| slope20 | `(EMA20_t-EMA20_(t-5))/ATR14_t`，无量纲 |
| RS63 | 个股最近 63 会话总回报减同频基准总回报 |
| RS percentile | 在当日合格证券全集上以 RS63 升序平均名次计算 `(rank-1)/(N-1)`；N<2 不可用 |
| ADV20 | 前 20 会话成交金额均值；用于数量限制的成交股数均值另存为 `ADV20_shares` |

EMA 的递推状态必须从固定数据起点/检查点延续，不能每天任意截断 60 根重算。最低新股观察期 252 会话；实际指标种子可更早。不同启动长度的误差检查参考 Freqtrade 的递归分析思路。[R26]

## 4. 股票池：全市场扫描不等于全市场买入

每日先以点时证券主表构建覆盖全集，再执行用户约束和数据条件。默认排除已退市、当时风险警示、当时不可交易、上市不足 252 会话、缺少关键市场规则的数据。历史上退市的证券仍必须在对应历史股票池与回测中保留。

价格范围与行业列表允许用户配置；未配置时不人为添加价格偏好。默认流动性起点为过去 20 会话平均成交金额不低于 2,000 万元人民币；其他货币必须显式换算或采用该市场的独立阈值。该数值是容量研究参数，不代表高于阈值就安全。

推荐形成过程固定为：

```text
授权覆盖全集 → 点时资格 → 用户价格/行业约束 → 数据和流动性
             → 市场状态 → 入场形态 → 交易几何 → 排序 → 账户风险分配
```

RS 分位在用户价格/行业筛选前的当日合格市场全集上计算。对同股票多形态先按 S-BR、S-H2、S-RG 选主计划；随后整个候选批次按 `RS分位降序、净RR降序、确认时间升序、instrument_id升序` 排序，再逐个分配组合额度。RS 缺失时不参加默认新仓排名并记录原因；不临时用 0 或最高分填补。

没有形态时只进入“观察雷达”，不能为凑推荐数量制造买入。价格/行业信息缺失时输出排除原因，不用零值填补。持仓股票即使不在新开仓池，仍持续执行风险监控。

## 5. 市场状态路由：明确、可重放、允许不交易

以下为本项目工程化起点，不宣称是 PA 原始实现或最优分类器。PA 的状态路由提供结构参考。[R03][R04]

### 5.1 大盘开仓闸门

`market_gate=RISK_ON` 需要：基准最近有效收盘高于 EMA120，且 EMA20 不低于 5 会话前的 EMA20。否则 `RISK_OFF`，不生成新增买入；缺基准或基准过期则 `UNKNOWN`，同样不新增。

已有仓位不因大盘闸门关闭而被程序虚构成已卖出。其原始退出策略继续执行，组合页显示风险；只有实际成交才能减少账面数量。该大盘过滤必须单独消融，未经验证不得自动增加更多指数条件。

### 5.2 个股分类，按优先级执行

| 优先级 | 状态 | 条件 | 新增策略 |
|---|---|---|---|
| 1 | `INVALID` | 关键数据、账户、市场规则或公司行为未通过校验 | 无 |
| 2 | `CHAOS` | `overlap10>=0.65` 且 `ER20<=0.20` 且 `abs(slope20)<=0.25` | 无 |
| 3 | `UPTREND` | `C>EMA20>EMA60` 且 `slope20>=0.25` 且 `ER20>=0.25` | S-BR、已批准的 S-H2 |
| 4 | `DOWNTREND` | `C<EMA20<EMA60` 且 `slope20<=-0.25` | 无新多头 |
| 5 | `BIASED_RANGE` | 不满足上列，且 `C>EMA60`、`EMA60_t>=EMA60_(t-5)`、有合格上下区域 | 仅已批准的 S-RG |
| 6 | `NEUTRAL` | 其他 | 无 |

只有大盘 `RISK_ON` 且个股允许时才评估新仓。周线 EMA20 一致性先作为记录特征，不默认增加闸门；后续作为单独挑战者测试。避免多个相似趋势指标叠加到几乎没有交易却未被察觉。

## 6. 支撑阻力引擎：SR-V3-inspired v0.1

### 6.1 两条实现路径

`upstream_research_adapter` 用于复现固定 SHA 的原仓库，以核对输入/输出与原始口径；须先完成许可检查。

`xq_sr_v01` 是本项目参考 V3 的独立工程化定义，作为默认核心。它与上游 V3 的数值不必相同，因此上游概率权重**不得直接用于此检测器**。选择哪条路径属于策略版本内容，不能运行中静默切换。[R12][R13]

### 6.2 xq_sr_v01 的确定性算法

使用截至 t 的最近 250 根有效日线，价格统一到 t 的尺度。基础分箱宽度为 `max(price_tick,0.25*ATR_t)`；若超过 4096 箱，按覆盖区间/4096 增大箱宽并向 tick 对齐，记录实际箱宽。

对每根 K 线，将成交股数乘 `2^(-age/60)` 后，按其高低区间与每个箱的重叠长度分摊；零幅棒全部落入最近箱。再把其收盘价作为点观察累计到收盘密度。两条曲线先用 σ=0.5ATR、截断半径 3σ 的离散高斯核平滑；边缘每个输入箱的分配权重重新归一，保持未归一化总量。再分别以自身最大值归一到 0–1，空曲线输出不可用，而不是全市场高质量。成交量守恒检查作用于未归一化量，不对已经无量纲化的分数比较股数。

首版枢轴采用 **k=2 的确认分形**：高点需严格高于左右各两棒高点；低点相反；平手不算枢轴。发生在 i 的枢轴只允许在 i+2 收盘后出现。用已确认高/低点分别构造高/低密度；每个枢轴权重为 `2^(-确认后会话数/120)`，以 σ=0.5ATR 的高斯核累计并按自身最大值归一化。之后可增加带确认时点的 ZigZag 挑战者。[R15]

位置曲线采用 `volume_density + 0.8*close_density + 1.6*pivot_density`。取正值局部峰值，平台相等时取最左峰；按位置分数降序、按中心价稳定排序打破平手；相邻中心至少间隔 0.9 ATR。区域先使用总宽度 0.6 ATR，边界按 tick 向外舍入，每侧最多 3 个。中心低于当前价的是支撑，高于当前价的是阻力；价格在区域内可标注 `CONTACTING`，不得谎称尚未触及。

区域的 `confirmed_pivot_count` 是当前窗口内同侧已确认枢轴价格落在区域边界内的数量。`stall_score=volume_density+0.8*close_density+0.3*区域宽度/ATR`，是可超过 1 的分数，不是概率。

历史事件数只统计**在 t 时点已完整观察后续 10 会话**的非重复接触段，段间隔至少 5 会话；记录 `hold/break/timeout` 全部类别。区域由当前历史推得时，这些属于历史几何描述，不是“过去真实发出的信号”。

`n_resolved=n_hold+n_break`，超时数量另存但不作为这个特征的已判定次数；训练 P-REACT 时仍保留全部成熟超时事件。

结构排序采用 `log1p(n_resolved) + 0.8*stale` 作为最小候选，`stale=1-2^(-age_since_last_contact/120)`；窗口内从未接触时取 1 并标记 `never_contacted=true`。这是参考上游分离位置/排序的设计，是否有效由消融决定；没有已判定历史事件的区域仍可展示，但不能假装有统计优势。[R12]

### 6.3 区域对象与冻结

```text
Level = {
  level_id, detector_version, data_snapshot_id, created_at, known_at,
  basis_session, basis_price_scale, low, high, center, atr_at_creation,
  kind, location_score, sr_structure_score, stall_score,
  confirmed_pivot_count, historical_resolved_count, last_contact_at,
  provenance, quality_flags
}
```

入场形态开始时冻结区域边界和版本，不能随着后续行情重新画区间后再宣布原突破成功。只有显式公司行为映射可改变价格尺度并留痕。新识别区域可以创建新 `level_id`，不得覆盖旧计划的区域。

## 7. 首个完整交易策略 S-BR：突破回测做多

### 7.1 冻结的定义

在会话 `b-1` 结束时，从当时已知阻力区域中选择最近的合格区域 Z，要求区域在该时点确实为阻力，且至少有两个已确认枢轴证据。若多区满足，先距离、再位置分数、最后 `level_id` 稳定排序。冻结 `z_low,z_high,A0=ATR_(b-1)`。

`b` 会话出现：`C_b > z_high+0.2*A0`、`C_b>O_b`、`CLV_b>=0.65`、`body_ratio_b>=0.50`，且 `TR_b<=2.5*A0`。使用 b 收盘时已知信息判断；不得在 b 开盘声称已知突破。极长高潮棒不追。

### 7.2 状态机

```text
IDLE → BREAKOUT_SEEN → HELD_ABOVE → RETEST_SEEN → CONFIRMED
                                                    ↓
                                     PLANNED → FILLED / EXPIRED
任一未成交状态 → INVALIDATED / EXPIRED → COOLDOWN → IDLE
```

| 转换 | 明确规则 |
|---|---|
| IDLE→BREAKOUT_SEEN | 满足突破棒条件；保存 b、Z、A0 |
| BREAKOUT_SEEN→HELD_ABOVE | 最早 b+1；至少一根后续收盘仍高于 `z_high` |
| HELD_ABOVE→RETEST_SEEN | 最早 b+2、最晚 b+10；某棒低点进入 `z_high±0.35*A0`，且收盘不低于 `z_low` |
| RETEST_SEEN→CONFIRMED | 回测棒自身或之后最多 2 会话内：阳线、CLV≥0.65，收盘>`z_high+0.1*A0`且收盘>前一棒高点 |
| CONFIRMED→PLANNED | 当时大盘/个股、目标空间、资金、风险全部通过 |
| 任意未成交→INVALIDATED | 任意收盘低于 `z_low-0.5*A0`、进入 INVALID/CHAOS/DOWNTREND、源区域不可再映射 |
| 任意未成交→EXPIRED | 总形态超过 b+12，或回测后两会话仍无确认，或计划未在下一会话执行窗口内成交 |
| 终态→COOLDOWN | 同股票同区域至少 5 会话不再产生同类新计划 |

状态每根棒最多前进一个阶段；唯一例外是 `RETEST_SEEN` 当棒可同时满足确认条件，因为两者均在该棒收盘才知道，实际执行仍在下一会话。不得在首次突破棒同时“突破、回测、买入”。每日更新状态前先检查已有计划的取消条件。

### 7.3 信号、价格与失效点

设确认日为 s，信号参考入场 `E_ref=C_s`。

```text
S0 = min(z_low, 从首次回测到s的最低价) - 0.20 * ATR_s
R_ref = E_ref - S0
允许 0.75*ATR_s <= R_ref <= 3.0*ATR_s
```

若有高于参考入场的合格阻力，最近阻力下沿减 `0.1*ATR_s` 为目标候选 T；不能越过最近明显阻力，只取更远目标来凑盈亏比。若没有更高的合格阻力，取 `T=E_ref+2*R_ref`，明确标为**风险倍数退出规则**，不是预测股价或虚构阻力。显示用的 MM 参考不替代该目标。

所有价格按证券 tick 对齐：买入区间下界向上取整、上限向下取整，保护阈值向下取整，目标向下取整。必须满足 `S0<E_ref<T`。以保守每股双边成本 `c` 计算：

```text
RR_net = (T - E_ref - c) / (E_ref - S0 + c)
要求 RR_net >= 1.5
```

最低佣金使 c 与数量相关时，先按参考数量求解，再对最终整手数量重新核验，不能按大单每股佣金应用到小单。

### 7.4 下一会话入场，不提前使用开盘信息

s 收盘生成**待确认计划**，有效期仅下一交易会话的配置执行窗口。入场允许区间为：

```text
lower = max(S0 + price_tick, E_ref - 0.25*ATR_s)
upper = E_ref + 0.50*ATR_s
```

次一会话实际可观察到执行报价时，重新检查价格区间、停牌/限制、真实可用现金、计划取消标志和 RR。价格超界就取消，不追、不把上限向上挪。计划数量在 s 已预留预算，执行时只能减少，不允许因低开自动加大数量。

日线参考回测将 `E=next_open+买入滑点` 作为执行估计，并同样受区间和风险检查。它是回放模型，不代表用户一定能在该价成交；仅有日线且开盘已触及买入限制价、没有可信排队/成交深度信息时，保守记为不成交并标记原因；不得读取当日最终收盘/总成交量来反过来决定开盘时下不下单。真实信号账本、参考仿真账本和实际成交账本必须分开。

在缺少盘中数据的本地人工模式，用户应在规定窗口核对价格并确认实际成交；系统未收到成交时不得自动创建真实仓位。交易计划过期不等于持仓已平仓。

### 7.5 退出：默认收盘判断、下一会话执行

入场绑定 `S0,T,R0=E-S0`，风险服务每日检查，按以下优先级生成退出计划：

| 优先级 | 原因 | 触发 |
|---|---|---|
| 1 | 人工紧急退出/账户强制约束 | 形成需确认操作，不伪造执行 |
| 2 | 已生效止损阈值 | `C_t <= S_active` |
| 3 | 结构失效 | 连续两次收盘低于 EMA60，或已有结构跌破条件触发 |
| 4 | 目标到达 | `C_t >= T` |
| 5 | 进展不足 | 已持有至少 5 会话，最高收盘浮盈未达 0.5R0，且 `C_t<EMA20_t` |
| 6 | 时间退出 | 从成交会话计数达到 20 会话 |

所有触发在 t 收盘后得到，最早下一可卖会话执行。EOD 模式下，仅盘中最高价碰目标或最低价穿阈值，**不记作已止盈/止损成交**；可以单独显示风险轨迹。上市板块的可卖数量、停牌、跌停排队等仍可能阻止退出。

跟踪阈值默认在最高收盘浮盈达到 1R0 后激活：`S_next=max(S_active, highest_close_since_entry-2.5*ATR_t)`。先用旧阈值判断本日退出，再计算新阈值，自下一会话生效；只能收紧，不能放宽。未达到激活条件时保持 S0。不采用未经验证的分批减仓，以免首版引入额外路径与归因歧义。

### 7.6 观察信号与操作信号的区别

`BREAKOUT_SEEN` 通知可以写“进入观察，等待回测”，不得写“立即买入”。只有 `PLANNED` 且通过组合预算、尚未过期的对象才可标为“可核对的操作计划”。未达到统计模型条件的规则策略仍可回测，但不得显示伪造的“预计胜率”。

## 8. 第二个策略 S-H2：上行回撤的二次确认

该模块是对 PA 双腿计数思想的工程化定义，不声称完整复刻所有主观 Brooks 形态；默认关闭，独立完成样本与状态测试后启用。[R06][R09]

状态顺序固定：`UP_LEG → PULLBACK_1 → ATTEMPT_1 → PULLBACK_2 → ATTEMPT_2_CONFIRMED`。

在 `UPTREND` 中保存最近已确认摆动高点与前一确认低点。第一回撤需要至少两个不同会话，且从该高点回落不少于 0.5 ATR（使用回撤开始时冻结 ATR）；回撤期间低点接近 EMA20 或已冻结支撑区域，距离不超过 0.5 ATR。首次收盘突破前一棒高点记 ATTEMPT_1，但首版不交易 H1。

ATTEMPT_1 后必须出现**新的**至少两会话回撤，其中至少一会话收盘低于前收盘，才进入 PULLBACK_2；连续高点上移不构成第二回撤。第二回撤累计幅度仍须不低于 0.5 个冻结 ATR，且不能收盘跌破前一确认低点减 0.2 ATR。第二次出现阳线、CLV≥0.65、收盘超过前一棒高点时，才产生 H2 确认。

每一腿保存开始、结束、极点和确认时点。第一回撤开始后最多 20 会话；出现新确认高点且超过原高点、趋势转空、混乱或结构失效时重置。每棒最多推进一个状态。两条回撤腿不能共享同一根棒。

止损为两腿最低价与绑定支撑下沿的较低者减 0.2 ATR；没有绑定支撑时使用两腿低点。目标、入场有效期、RR、持仓退出、风险预算与 S-BR 相同。不得借 H2 标签自动赋予比其他形态更高的获利概率。

## 9. 第三个策略 S-RG：偏多区间下边缘反弹

该模块只处理 `BIASED_RANGE`，不是所有横盘股票的抄底器，且默认关闭。中性区间不交易，保持与 PA 方向约束的基本思想一致。[R07]

上下区域在首次接近下沿之前冻结，各至少两次已确认枢轴证据，两个区域中心距离位于 3–8 ATR。入场位置必须处于整个区间下三分之一且距离下方支撑区域不超过 0.35 ATR。出现阳线、CLV≥0.65、收盘重新高于支撑区域上沿、收盘突破前一棒高点后，下一会话按共同执行规则核验。

初始阈值设在支撑下沿与确认棒低点较低者下方 0.2 ATR；目标为上方阻力下沿减 0.1 ATR。没有明确对侧区域则不交易，不用 2R 人造目标弥补无边界的区间。RR 必须达标。最大持有期 10 会话，其他退出规则沿用公共策略契约。

若区间中部、下行趋势、扩张失控或 CHAOS，则不产生新多头；区间下沿被跌破不是“便宜了再加仓”。

## 10. 独立基线与挑战者

这些对象必须能单独回测和比较，不能只在代码里作为几个布尔指标。

| ID | 完整但简化的交易定义 | 用途 |
|---|---|---|
| `B-CASH` | 相同现金账户，不开仓；按配置计算现金利息，没有配置则 0 | 验证策略是否优于不交易 |
| `B-HOLD` | 匹配市场可投资基准与明确建仓规则，计分红、费用 | 检验相对收益与风险暴露 |
| `B-EMA` | 收盘 EMA20 上穿 EMA60 后下一会话买；下穿后下一会话卖；无额外形态 | 检验复杂化是否有收益贡献 |
| `B-DC` | `C_t>max(H_(t-20..t-1))` 后下一会话买；`C_t<min(L_(t-10..t-1))` 或固定 2ATR 风险阈值收盘失守后退出 | 参考 Turtle 的长多无加仓改写 [R19] |
| `B-MOM` | 月末对 `TR_(t-21)/TR_(t-252)-1` 排名，取前 K；等权目标，下一会话调仓，限制每期更换数量 | 参考滞后动量与 TopkDropout 的长多改写 [R21][R24] |
| `C-BOLL` | 上一会话确定的 Boll(20,2) 上轨被收盘突破且 CCI20>0，下一会话买；收盘跌破 EMA20 或 ATR 跟踪阈值后退出 | 参考 Boll/CCI 的日线挑战者，非原参数复现 [R20] |
| `C-ML` | 用经验证模型得分排序，按相同组合约束和换手规则形成目标 | 研究独立预测能力，不作为“AI 必胜”模块 [R22–R24] |

没有结构止损定义的基线，以 2ATR 压力距离做仓位预算，并明确这只是预算基准，不伪装成该基线自带止损。额外加共同保护退出时，登记为独立 `+risk_overlay` 版本，不能悄悄修改原基线。

所有技术策略采用相同市场约束、成本与下一会话口径。基准比较至少提供两套：各策略本来定义的资金暴露，以及统一敞口/风险预算后的比较。不能用主策略只有 20% 仓位的收益率直接与满仓基准得出“无效/有效”，却不显示敞口、波动与回撤。

B-DC 中窗口必须排除当前棒，否则 `C_t > max(含H_t的窗口)` 在正常 OHLC 下无法成立。多周期窗口的 `shift`、价格单位和标签时点必须有专门测试。

## 11. 组合风险与仓位数量

### 11.1 默认参数，全部属于待确认的风险配置

| 参数 | 起点 | 说明 |
|---|---:|---|
| 每笔计划风险预算 | 净资产的 0.25% | 含预设跳空缓冲与预估成本，不是最大实际亏损保证 |
| 单股票市值上限 | 净资产的 10% | 包含该股票已有手工仓位与未成交计划 |
| 单行业敞口上限 | 净资产的 25% | 行业未知按独立受限桶，不当作“分散” |
| 总多头市值上限 | 净资产的 80% | 无融资、无负现金 |
| 持仓股票数上限 | 8 | 按账户唯一证券数，不按策略实例数 |
| 组合计划风险上限 | 净资产的 2% | 现仓+新计划；不因浮盈就把隔夜风险记为 0 |
| 单次交易容量上限 | ADV20 股数的 0.1% | 容量研究起点；日线 ADV 不能保证开盘容量 |
| 隔夜缓冲 | 每股 0.5 ATR | 用于预算；实际跳空可能超过缓冲 |
| 策略级暂停新增 | 高水位回撤超过用户设定阈值，模板为 10% | 不自动销毁仓位或忽略退出；人工复核后恢复 |

持有手工股票但没有可信保护阈值时，以 `max(2*ATR, 市值对应的配置压力跌幅)` 估算压力风险；缺 ATR/估值则标为未知风险并暂停新增，不能默认零风险。行业等约束必须以最近可用且有时间标记的信息计算。

### 11.2 数量计算

设权益 V、入场 E、止损阈值 S、每股成本 c、跳空缓冲 g。基础每股预算风险：

```text
r_share = max(E-S, price_tick) + g + c
q_risk = floor(V * risk_fraction / r_share)
q_cap = floor(剩余单股市值预算 / E)
q_cash = 最大满足 q*E + entry_fee(q) <= 未冻结可用现金 的整数q
q_liquidity = floor(ADV20_shares * 0.001)
q_pre = min(q_risk, q_cap, q_cash, q_liquidity, 行业/总敞口余量允许的数量)
q = market_rules.normalize_buy_quantity(q_pre)
```

不能全市场固定“100 股一手”。最小数量、递增单位、零股卖出、价格跳动和可卖时间均来自证券适用规则。数量规范化后必须重新计算最低佣金、RR、现金、总风险，直到满足或 q=0；q=0 就跳过，禁止凑一手超过风险。

现仓预算风险以当前估值到已生效保护阈值的距离加跳空/费用缓冲估算，而不是始终使用原始买入价；跟踪阈值高于买入价时仍保留隔夜风险。

入场前为计划冻结风险与现金额度，多个策略并发不能重复使用同一额度。真实成交部分执行时只管理实际数量，剩余部分取消或继续执行必须明确，首版默认取消未成交余量并解冻预算。

### 11.3 风险优先关系

`数据/账户真实性 > 市场交易限制 > 组合硬风险 > 已持仓退出 > 新策略信号 > 排名/解释`。

预测高概率不能绕过风险；用户临时修改参数必须生成审计事件，不能改写过去结果。对受 T+1 或其他可卖限制影响的头寸，触发风险阈值也不能按不可实现的同日卖出记收益。市场参数应按规则生效日建模，而不是写死“所有证券都一样”。[R34]

## 12. 预测模块：先定义问题，再训练模型

### 12.1 上游双概率模型的继承边界

借鉴上游把“接触区域”和“接触后反应”拆开的方法，但不直接加载其系数或照搬排除未决的训练集。新检测器、新频率、新区域宽度或新标签，都必须形成新的任务版本。[R13][R17]

| 任务 | 预测时点与特征 | 目标及用途 |
|---|---|---|
| `P-TOUCH-v1` | 区域冻结时的 X_t | 未来 40 会话内，从正确方向实际接触区域的概率；用于观察雷达 |
| `P-REACT-v1` | 同一个冻结时点的 X_t，条件为之后确有接触 | 接触后明确 `hold/break/timeout` 的条件分布；用于区域研究 |
| `P-TRADE-v1` | 交易确认时点 X_s，含执行口径与形态 | 按同一策略模拟执行后的净收益分布；用于交易过滤 |
| `P-RETURN-h` | s 收盘 X_s | 从 s+1 开盘到 s+1+h 开盘的总回报分布，h∈{1,5,20}；不混用即时涨跌 |

`P-RETURN` 的一会话收益不是“今天买入今天卖出”的收益，且回测需考虑最早可卖时点、费用和股票终止交易处理。没有合适公司行为/终值数据的样本不能悄悄删除而不报告。

### 12.2 P-TOUCH 和 P-REACT 的标签精确定义

冻结时价格必须在区域正确一侧。支撑的正确接触是此前价格在区域上方，后续某根完整高低区间与区域有交集；阻力反向。若价格直接跳过整个区域、该棒亦无交集，则记 `gap_invalidation`，与真实接触分开，不伪造区间成交。

P-TOUCH 的事件是 40 会话内、且在 gap_invalidation 之前发生接触。接触前 gap_invalidation 是竞争终态，计入非接触类别并单列数量。没有接触且窗口完整结束为 no_contact；数据截断、无法观察后续或不可解释终止为 censored。首版逻辑回归对完整结果做接触/非接触分类，同时报告竞争终态占比。

对接触日 j：若支撑在 j 收盘已经低于 `z_low-0.5*A0`，立即记 break；否则在 j+1 至 j+10 的收盘序列中，首先收于 `z_high+1.0*A0` 上方为 hold，首先收于 `z_low-0.5*A0` 下方为 break。阻力按方向对称。完整观察 10 会话均未发生为 timeout。采用收盘判定，避免同一 OHLC 棒无法确定先后；j 收盘后的未来 10 会话不包含 j 本身。

首版为统一样本成熟政策，只有 `j+10` 已经过且数据有效才纳入反应训练，即使早期已判定也等待该窗口成熟。**未成熟是 censored，不是 timeout。** 当行情缺数不能判断路径时，保留质量标记，不制造标签。

该定义与上游不同，必须重新训练。它仍然是区域反应任务，不能自动当作 S-BR 成交后的交易盈利任务。S-BR 已经历回测后，原区域接触是已发生事实，此时不拿预测 P-TOUCH 当新增买入门槛。

### 12.3 P-TRADE 的标签与执行选择

记录所有合格候选，包括被风控拒绝、价格超界、未成交、人工忽略的候选。模型训练分开处理“可成交性”和“成交后收益”，不能把未成交行当零收益盈利样本，也不能只选择人工愿意交易的赢家。

成交后标签来自同一执行模拟器，包含退出原因、净收益、以初始 R0 归一的净 R 倍数、最大不利/有利变动、持仓期。盈利概率为 `P(net_pnl>0 | 可执行入场, X_s)`；收益期望用全部成交结果估计，包括时间退出和其他中间收益，不套用只有固定 TP/SL 两结局的公式。

实时入场价格相比训练参考的漂移若超过允许区间，模型失配，直接取消或用匹配执行模型重新评估；不能只替换价格而保持原获利概率。

### 12.4 训练顺序与校准

先建立基准发生率、正则逻辑回归/线性回归；确认数据和标签正确后，才引入 LightGBM 与挑选后的 Alpha158 特征。标准化、缺失值处理、特征选择及概率校准全部只拟合对应训练/验证段。Qlib 提供的是工作流和特征参考，不提供对本任务的效果担保。[R22][R23]

校准采用单独验证段上的 sigmoid 或足够数据下的 isotonic；必须展示可靠性分箱、样本数量、Brier/log-loss 及发生率基线。AUC 表示排序能力，不等于概率准确；校准也不自动创造盈利能力。预测区间应报告实际覆盖率，而不是把一个模型分数重新缩放成“可信度”。[R32]

### 12.5 统计过滤模式

`rule_only` 与 `statistical_filter` 是不同的已冻结策略版本。后者要求匹配 `detector_version, feature_schema_hash, label_version, execution_profile, market, horizon` 的模型，才允许使用 P-TRADE 的净收益期望进行过滤。

初始过滤规则可设为：验证段确定的预期净 R 门槛不低于 0；在最终样本外验证其过滤后收益及覆盖率。没有通过验证或模型过期时 `ABSTAIN_MODEL_UNAVAILABLE`，不得静默切换成未批准的规则版本。合法的规则版可以作为独立已批准实例继续运行，但应产生可见的部署切换记录。

不输出通用“胜率至少 60% 才买”。低胜率高赔率、时间退出、成本和不成交都必须进入真实收益分布。

## 13. 回测、验证与上线条件

### 13.1 同一引擎三种运行

`HistoricalReplay`、`PaperRunner`、`LiveAssistRunner` 必须调用同一策略状态函数和同一风险服务。不同之处仅是事件来源、时钟和成交适配器。历史模式禁用网络与系统当前时间，事件可重复排序；随机数使用固定种子和稳定哈希，不能用进程随机化的内建字符串 hash 生成跨进程实验种子。

回测必须包括现金、佣金最低值、卖出税费、股数/价位规则、复权映射、分红、停牌、终止交易、无法成交、拒绝计划、部分成交和资金冻结。未知终止回收价值不能直接沿用最后价格无限持有，应显示未决估值和压力情景。

### 13.2 时间外切分

起点采用滚动 `训练36个月 → 验证6个月 → 测试3个月`，测试段互不重叠。最终另留从未用于调参的保留段。时间长度不足时输出证据不足，不能随机拆股票×日期样本凑齐。

**按交易日期组切分面板数据**，同一天不同股票不散落训练与验证。再按每条样本的 `[feature_asof,label_end_at]` 区间清除与验证/测试标签窗口重叠的训练样本。只在一维日期上设 gap 不足以自动解决所有多标的重叠标签；需要本项目区间 purge。[R33]

区域任务可能需要 40 会话等接触、再 10 会话等反应；不能简单只隔 5 或 20 根。实际 purge 以各样本 label_end_at 为准。跨股票留出另做稳健性评测，不取代时间切分。

### 13.3 必须报告的成绩

| 类别 | 必须包含 |
|---|---|
| 数据 | 点时覆盖率、丢失/停牌/删去原因、退市样本、价格/公司行为版本 |
| 交易 | 信号数、可执行数、实际/仿真成交数、拒绝/过期数、成本、换手、持仓期 |
| 收益风险 | 成本后总收益/年化、波动、最大回撤、Calmar、按同口径计算的 Sharpe、净 R 分布、敞口 |
| 对比 | 现金、可投资基准、EMA、Donchian、无 SR、无 RS、无市场闸门等消融 |
| 稳健性 | 分年度、市场状态、行业、流动性与股票贡献；成本翻倍、额外跳空和执行延迟情景 |
| 概率 | Brier、log-loss、校准图、样本数/基线、覆盖率；按完整事件定义分组 |
| 可信度 | 按时间块重采样的区间；实验尝试数；最终保留段是否被查看过 |

高相关、同日出现的多只股票信号不按完全独立样本计算显著性。基础重采样使用连续交易日期块，将同一日期所有股票一起抽取，块长至少覆盖目标/持仓依赖尺度，并提供块长敏感性分析；独立逐交易 bootstrap 只能作为对照。

### 13.4 参数研究纪律

第一次研究预注册不超过 24 个组合，只搜索 2–3 个最重要参数，例如回测容忍度、最小 RR、时间退出；不一次搜索几十个指标权重。所有尝试包括失败、超时、无交易都入库。用验证段选定一个参数版本，再一次性评测最终保留段。看到结果后修改就属于新研究，原保留段不再是新模型的“未看过测试集”。

默认执行消融顺序：简单突破基线→加回测确认→加 SR 区域→加相对强弱排序→加市场闸门→加统计过滤。若某层增加复杂度却未改善样本外风险收益/稳定性，就移出默认组合。

### 13.5 晋级规则

工程门槛是硬约束：所有关键测试通过，来源/版本完整，无已知未来依赖，执行模型可解释，风险不能被绕过。

研究门槛默认要求至少 4 个互不重叠时间外测试段、100 笔完整成交结果，并展示集中度与不确定性；这些是证据量起点，不是盈利证明。净期望的时间块重采样区间仍跨 0 时，状态是 `INCONCLUSIVE`，不能包装为已证实优势。策略也应符合用户设定回撤容忍度；回撤容忍度未填写不得批准真实资金辅助。

进入 `LIVE_ASSIST` 前，至少有 60 个交易会话的影子观察及足够的实际可执行计划对照，模板设为 20 次；样本不足继续观察，不扩大仓位凑样本。人工确认、成交回传、休眠恢复、通知延迟与拒绝执行均属于验收内容。上述为系统政策，不是对未来收益的承诺。

## 14. 一个可核对的计划算例

以下是合成算例，不指向真实股票。

```text
账户权益：100,000 元；每笔风险预算：250 元
信号确认收盘参考：10.00 元；ATR：0.50 元
下一会话参考成交（含滑点）：10.05 元
冻结保护阈值：9.40 元；冻结目标：11.40 元
示例双边每股成本：0.03 元（实际系统由数量和费率函数计算）
隔夜缓冲：0.25 元；示例买入单位：100 股
```

实际价差风险 `10.05-9.40=0.65` 元；每股预算风险 `0.65+0.25+0.03=0.93` 元。风险允许数量为 `floor(250/0.93)=268` 股，按示例单位向下规范化为 200 股；仍需检查现金、行业、总敞口和流动性约束。

净结构 RR 为 `(11.40-10.05-0.03)/(10.05-9.40+0.03)≈1.94`，超过默认 1.5。名义投入为 2,010 元、预算风险为 186 元。但日线退出可能在更低的次日价格成交，真实损失仍可能超过 186 元；它不是风险上限保证。

若行情跳到入场上限之外、用户错过执行窗口、或最新权益不足，计划取消。不能为了“有一笔交易”放宽入场价格、移动止损或增加股数。

## 16. 首版完成的定义

首版不是“有一个策略页面”。它必须能在本地从固定行情快照出发，运行 S-BR 和至少两个基线，生成逐棒状态轨迹、真实约束下的参考成交、费用/权益曲线、拒绝原因、与同一输入下完全一致的重跑结果。之后接上策略版本管理、仿真、通知与真实成交复盘。

当数据或证据不足时，系统必须能明确输出“暂无达到部署条件的策略”，同时保留全部研究工作。这比把未验证的策略包装成现成赚钱系统更接近实际可用的量化工程。
